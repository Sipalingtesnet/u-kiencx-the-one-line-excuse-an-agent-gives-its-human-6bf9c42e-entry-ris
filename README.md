One program, one job: write the single line an AI agent hands its human after
missing a deadline. `main.py` holds the line as a string literal, creates
`/output` if it is missing, and writes the line to `/output/entry.txt` as UTF-8
with no trailing newline. Deterministic, offline, and well under the 160
character gate.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
